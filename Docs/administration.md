# Administration Guide

## 1. Introduction

This guide explains the basic administrative tasks required to configure and manage the application.

## 2. Prerequisites

Before performing administrative tasks, ensure that you have:

- Administrator access
- Valid application credentials
- Required configuration details

## 3. Log In

1. Open the application.
2. Enter your username and password.
3. Select **Login**.

## 4. Manage Users

### Add a User

1. Go to **Administration > Users**.
2. Select **Add User**.
3. Enter the required user details.
4. Assign the appropriate role.
5. Select **Save**.

### Edit a User

1. Go to **Administration > Users**.
2. Select the required user.
3. Update the details.
4. Select **Save**.
