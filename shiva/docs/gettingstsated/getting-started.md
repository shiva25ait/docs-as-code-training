 # Getting Started Guide

## 1. Introduction

This guide provides the basic steps to help you get started with the application.

## 2. Prerequisites

Before you begin, make sure you have:

- A valid user account
- Application access
- A supported web browser

## 3. Sign In

1. Open the application.
2. Enter your **Username** and **Password**.
3. Select **Sign In**.

## 4. Navigate the Application

After signing in, the **Home** page is displayed.

Use the navigation menu to access the available features and modules.

## 5. Perform a Basic Task

1. Select the required module.
2. Select **Create** or **Add**.
3. Enter the required information.
4. Select **Save**.

## 6. Sign Out

1. Select your **Profile** icon.
2. Select **Sign Out**.

## 7. Next Steps

For more information, refer to the relevant user guides.
